# Sanjaya

**The live voice agent that watches every change on the factory floor.**
AI Builder Camp 2026 · Track: Manufacturing: Intelligent Operations & Industrial Efficiency

Every industrial disaster is a stack of small changes that each looked fine. Sanjaya sees the stack forming,
asks the right person for a decision by voice, and watches the decision until it is safely done.

## What you'll see

| Screen | What it shows |
|---|---|
| **Command center** (`#/command`) | Live floor map: areas glow as risk builds, the steam line stops when the boiler is off, changes pulse on the equipment they touch. **Swiss-cheese risk stack**: each safeguard is a slice; weakened ones open a hole and the hazard's path travels through them, stopping at the first intact slice ("only 2 safeguards left between the hazard and people"). **Sanjaya's mind**: every step Sanjaya takes, live, with the document and page it relied on. Change timeline, decisions, audit trail. |
| **Phone app** (`#/phone/<person>`) | The plant group chat. Hindi voice notes, photos and datasheets in; spoken evaluations, approval cards, read-back, Hindi relay, countdown ring, like-for-like part reports and risk alerts out. Every Sanjaya message has "How I decided". Anyone can ask "Sanjaya, …". |
| **Live call** (on an approval card, Gemini mode) | The approver talks to Sanjaya in real time (Gemini Live API): asks "why?", gets answers quoted from the SOPs, gives the decision by voice, hears it read back. |
| **Teach Sanjaya** (`#/teach`) | Upload a plant's HAZOP and SOP PDFs. Gemini drafts the risk model (hazards, safeguards, limits, each cited to its page, plus gaps to check). The safety officer approves it. |
| **Stage view** (`#/stage`) | Two phones and the command center on one screen, for live demos and recording the video. |

## How it works

```
 phones (chat, voice, photos, PDFs) ──► FastAPI + WebSockets ──► Engine (state, approvals, timers, audit)
                                              │                        │
                                   Gemini: perceive & classify   Deterministic guardrails:
                                   (voice, photos, datasheets),  limits only from cited plant docs,
                                   agent with read-only tools,   risk stack, like-for-like rules,
                                   Live API voice calls,         read-back before relay,
                                   risk-model drafting           escalation, never approves
```

- **Gemini reads; code decides.** Gemini turns voice notes, photos, datasheets and documents into schema-validated
  JSON and answers questions through read-only tools (`get_risk_stacks`, `search_documents`, `get_limit`…). Limits,
  risk levels and pass/fail verdicts are deterministic code against the plant's own documents, so Sanjaya can't
  invent a safety number. Answers containing a number no tool returned are rejected.
- **Plant documents** (`data/docs/`, generated by `scripts/make_plant_docs.py`): a HAZOP report, SOPs, a process
  validation report and an area classification for the fictional Plant X. Every rule and limit Sanjaya quotes is
  cited to its section and page.
- **Offline mode:** without a Gemini key (or if a call fails), keyword rules that understand the demo's English,
  Hinglish and Hindi take over, and onboarding shows the pre-computed extraction. The header always says which mode
  is running. Live calls need Gemini.

Code map: `app/engine.py` (flows, trace, guardrails) · `app/gemini.py` (Gemini calls and the tool-calling agent) ·
`app/live.py` (Live API voice proxy) · `app/onboarding.py` (risk-model drafting) · `app/risk.py` (stack detection) ·
`app/parts.py` (like-for-like) · `app/docs.py` (document search and citations) · `web/` (React app).

## Run locally

```bash
pip install -r requirements.txt
export GEMINI_API_KEY=...          # optional; without it Sanjaya runs in offline mode
uvicorn app.main:app --port 8080
```

Open http://localhost:8080. Check which Gemini model it picked at http://localhost:8080/api/gemini. The built React app is committed in `static/`, so Node isn't needed to run it.
To change the frontend: `cd web && npm install && npm run dev` (hot reload, proxies to :8080), then `npm run build`.

Tests: `pip install -r requirements-dev.txt && pytest -q` (the whole demo story end to end, offline).

## Demo script

Open the stage view (`#/stage`) or several phones, press 🎬, set the clock to 20×, and click through:
1. **Watch:** Hindi voice note (batch raised to 480 kg) → muted-alarm photo → trainee on the night shift → the
   spray dryer goes critical, 3 holes line up, Ravi and Meena hear the warning.
2. **Approve:** Arjun asks to shut down Boiler B-1 → Ravi hears the evaluation quoting SOP-R201-07 §4.2 → "Yes, but
   15 minutes max" (by voice, button or live call) → read-back → Arjun hears the approval in Hindi → countdown, steam
   line stops on the map → back on.
3. **Evaluate:** gas detector into maintenance → Priya asks about Supplier B's cheaper fan → report: 12.5% less air,
   no Ex certificate, T3 motor, mild-steel impeller → then a nameplate photo shows it was installed anyway.
4. **Ask:** "Sanjaya, boiler kitni der band kar sakte hain?" → answer cited to the SOP.
5. **Teach:** `#/teach` → "Use Plant X samples" → draft risk model with page citations → approve.

## Deploy to Cloud Run

```bash
gcloud run deploy sanjaya --source . --region asia-south1 --allow-unauthenticated \
  --set-env-vars GEMINI_API_KEY=YOUR_KEY,SANJAYA_DEMO_SPEED=20 \
  --max-instances 1 --session-affinity --timeout 3600
```

The Dockerfile builds the React app and the server. `--max-instances 1` keeps everyone in the same in-memory chat;
`--timeout 3600` keeps WebSockets open. Cloud Run serves HTTPS, which phones require for the microphone.

## Configuration

| Variable | Default | Meaning |
|---|---|---|
| `GEMINI_API_KEY` | none | Turns on Gemini. Without it, offline mode. |
| `GEMINI_MODEL` | auto | Leave unset: Sanjaya lists the models your key can use and picks the newest Flash, switching automatically if one is busy (503) or retired (404). Set it only to force a model. |
| `GEMINI_LIVE_MODEL` | auto | Live API model for voice calls; discovered from your key's models if unset. |
| `SANJAYA_DEMO_SPEED` | `1` | Demo clock multiplier (also adjustable live in the 🎬 drawer). |
| `SANJAYA_ESCALATE_AFTER_MIN` | `3` | Plant minutes before an unanswered request escalates. |
| `SANJAYA_REMIND_BEFORE_MIN` | `5` | Plant minutes before the limit at which the requester is reminded. |

*All plant data, people, documents, datasheets and photos are fictional.*
